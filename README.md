# Daxator Packages

Daxator Studios' sales and billing app: packages and pricing, a calculator, quotes, invoices (DAX001…), agreements, trial-shoot tracking and client records.

- Single-page app (`index.html`), works offline after the first load.
- Data is stored in the browser on each device. Use **Backup / Restore** in the app to move it between devices.
- Deployed on Vercel; every push to `main` goes live automatically.
